# Flashcard Quiz App 📱

A mobile application built with **Flutter** to help users learn and memorize information using digital flashcards.

## Features ✨
- **Create & Manage:** Easily add, edit, or delete your flashcards.
- **Quiz Mode:** Interactive card flipping to test your knowledge.
- **Data Persistence:** Your cards are saved automatically for future use.

## Technologies Used 🛠️
- **Framework:** Flutter
- **Language:** Dart
- **State Management:** Provider
